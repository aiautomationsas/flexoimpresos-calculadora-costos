# Scripts de Debug

Este directorio contiene scripts para debugging y diagnóstico.

**⚠️ Estos archivos NO deben usarse en producción.**

## Archivos

| Script | Descripción |
|--------|-------------|
| `debug_repeticiones_app.py` | Debug de repeticiones y cilindros |
| `debug_troquel_directo.py` | Debug de cálculo de troquel directo |
| `debug_troquel_existe.py` | Debug de flag troquel_existe |
| `debug_troquel_simple.py` | Debug simplificado de troquel |

## Uso

```bash
cd /path/to/proyecto
python scripts/debug/debug_troquel_simple.py
```
